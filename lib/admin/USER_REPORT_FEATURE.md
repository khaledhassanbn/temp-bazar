## 🔄 كيف يعمل النظام؟

### 1️⃣ المستخدم يفتح صفحة صنايعي أو متجر
- يرى زر الإبلاغ في AppBar
- الزر **لا يظهر** إذا كان هو صاحب الصفحة

### 2️⃣ المستخدم ينقر على زر الإبلاغ
- يفتح Dialog بعنوان "إبلاغ"
- يعرض اسم المُبلَّغ عنه
- يوفر حقل نصي لإدخال السبب

### 3️⃣ المستخدم يكتب سبب البلاغ
- الحد الأدنى: 10 أحرف
- الحد الأقصى: 500 حرف
- التحقق من الصحة تلقائي

### 4️⃣ المستخدم ينقر "إرسال البلاغ"
- التحقق من تسجيل الدخول
- إرسال البلاغ إلى Firestore
- عرض رسالة نجاح خضراء
- إغلاق Dialog تلقائياً

### 5️⃣ البلاغ يظهر في لوحة الأدمن
- في قائمة "البلاغات المعلقة"
- مع جميع التفاصيل
- الأدمن يمكنه حله/رفضه/حذف الحساب

## 📊 البيانات المُرسَلة

عند إرسال البلاغ، يتم إنشاء مستند في `user_reports` collection:

```javascript
{
  id: "auto_id",
  reporterId: "current_user_id",    // معرف المُبلِغ
  targetId: "craftsman_or_store_id", // معرف المُبلَغ عنه
  targetType: "craftsman",           // أو "store" أو "courier"
  reason: "النص الذي كتبه المستخدم",
  status: "pending",                 // الحالة الافتراضية
  createdAt: Timestamp.now(),
  resolution: null,
  resolvedAt: null,
  resolvedBy: null
}
```

**بالإضافة إلى**:
- يتم زيادة `reportCount` في حساب المُبلَغ عنه (`craftsmen` أو `markets` collection)
