# 🚀 دليل البدء السريع - نظام إدارة الأدمن

## ⚡ البدء في 3 خطوات

### 1️⃣ الوصول من القائمة الجانبية
افتح القائمة الجانبية للأدمن واختر:
- 📊 **لوحة التحكم الإدارية**
- 🚨 **بلاغات المستخدمين**
- 👤 **إدارة المستخدمين**

### 2️⃣ الوصول برمجياً
```dart
// لوحة التحكم
Navigator.pushNamed(context, '/admin/management');

// البلاغات
Navigator.pushNamed(context, '/admin/user-reports');

// المستخدمين
Navigator.pushNamed(
  context,
  '/admin/users-management',
  arguments: {'tab': 0}, // 0=صنايعية, 1=متاجر, 2=كوريرات
);
```

### 3️⃣ ابدأ الاستخدام!
جميع الصفحات جاهزة وتعمل الآن ✅

## 📋 حالات الاستخدام الشائعة

### إدارة البلاغ
```dart
// 1. افتح قائمة البلاغات
Navigator.pushNamed(context, '/admin/user-reports');

// 2. انقر على بلاغ لعرض التفاصيل

// 3. اختر إجراء:
// - حل البلاغ ✅
// - رفض البلاغ ❌
// - حذف الحساب المبلغ عنه 🗑️
```

### إدارة المستخدم
```dart
// 1. افتح قائمة المستخدمين
Navigator.pushNamed(
  context,
  '/admin/users-management',
  arguments: {'tab': 0}, // صنايعية
);

// 2. اختر فلتر الحالة (معلق، نشط، إلخ)

// 3. انقر على مستخدم لعرض التفاصيل

// 4. اختر إجراء حسب الحالة:
// - معلق: قبول ✅ | رفض ❌
// - نشط: تعليق ⏸️ | حظر 🚫
// - معلق/محظور: تفعيل ▶️
// - محذوف: استعادة ↩️
```

### حذف صورة من معرض الأعمال
```dart
// 1. افتح تفاصيل صنايعي
Navigator.pushNamed(
  context,
  '/admin/user-management-detail',
  arguments: {
    'userId': 'craftsman_id',
    'userType': 'craftsman',
  },
);

// 2. اذهب لقسم معرض الأعمال

// 3. انقر على أيقونة الحذف (X) على الصورة

// 4. أكد الحذف ✅
```

## 💡 نصائح سريعة

### للأدمن:
✅ راجع البلاغات المعلقة يومياً  
✅ استخدم الفلاتر لتنظيم العرض  
✅ راجع معرض الأعمال قبل قبول الصنايعية  
✅ اكتب أسباب واضحة عند الرفض/التعليق/الحظر  

### للمطورين:
✅ جميع الخدمات في `admin/services/services.dart`  
✅ جميع الواجهات في `admin/widgets/widgets.dart`  
✅ جميع النماذج في `admin/models/models.dart`  
✅ استخدم StreamBuilder للتحديث الفوري

## 🔍 مثال كامل: معالجة بلاغ

```dart
// 1. المستخدم يفتح قائمة البلاغات
Navigator.pushNamed(context, '/admin/user-reports');

// 2. الصفحة تعرض جميع البلاغات مع StreamBuilder
// - فلترة حسب الحالة: معلق، قيد المراجعة، تم الحل، مرفوض
// - عرض معلومات البلاغ: المُبلِغ، المبلغ عنه، السبب

// 3. المستخدم ينقر على بلاغ معين
// الانتقال لصفحة التفاصيل مع تمرير كائن UserReport

// 4. في صفحة التفاصيل:
// - عرض تفاصيل البلاغ الكاملة
// - عرض عداد البلاغات للحساب المبلغ عنه
// - أزرار الإجراءات (حل، رفض، حذف)

// 5. المستخدم يختار "حل البلاغ"
// - يدخل تفاصيل الحل (≥10 أحرف)
// - النظام يحدث حالة البلاغ إلى "resolved"
// - يحفظ تفاصيل الحل وتاريخه ومعرف الأدمن

// 6. النظام يعرض رسالة نجاح
// - "تم حل البلاغ بنجاح"
// - يعود للقائمة تلقائياً
```

## ⚠️ ملاحظات مهمة

### 1. الحذف الناعم
- عند حذف حساب، لا يتم حذفه فعلياً
- يتم تعيين `adminStatus = 'deleted'`
- يتم تحويل `role` في users إلى `'user'`
- يمكن استعادة الحساب لاحقاً

### 2. التحديث الفوري
- جميع القوائم تستخدم StreamBuilder
- التحديثات تظهر فوراً بدون إعادة تحميل

### 3. معالجة الأخطاء
- جميع العمليات لها مهلة 30 ثانية
- رسائل خطأ واضحة بالعربية
- التأكيد قبل الإجراءات الحرجة
