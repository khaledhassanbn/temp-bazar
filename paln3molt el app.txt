2.2 استراتيجية الخصم (Commission Deduction Strategy)

النقطة المثالية للخصم

الخصم يتم عند تحويل الطلب إلى isActive: false مع حالة delivered/completed — أي داخل OrderService.moveToPastOrder() الموجود حالياً.

Order Delivered → moveToPastOrder() → deductCommission() → updateStatistics()

Idempotency Protection (حماية من الخصم المكرر)

// Inside Firestore Transaction:
1. قراءة order document
2. التحقق: if (orderData['commissionDeducted'] == true) → SKIP
3. قراءة market document → الحصول على commissionRate
4. قراءة user document → الحصول على walletBalance الحالي
5. حساب العمولة: 
   - fixed: commissionRate
   - percentage: totalAmount * (commissionRate / 100)
6. خصم: walletBalance -= commissionAmount (يُسمح بالسالب)
7. تحديث order: commissionDeducted = true, commissionAmount, commissionDeductedAt
8. تحديث user: walletBalance
9. تحديث market: totalCommissionsPaid += commissionAmount
10. إنشاء wallet_ledger entry

[!IMPORTANT]كل هذه العمليات يجب أن تتم داخل runTransaction واحد لضمان الـ Atomicity وحماية من Race Conditions.

2.3 نظام الحد الائتماني (Credit Limit System)

منطق التحقق عند إنشاء طلب جديد

Future<bool> canStoreReceiveNewOrders(String storeId) async {
  final storeDoc = await _firestore.collection('markets').doc(storeId).get();
  final ownerUid = storeDoc.data()?['ownerId'];
  final creditLimit = (storeDoc.data()?['creditLimit'] ?? -50).toDouble();
  
  final userDoc = await _firestore.collection('users').doc(ownerUid).get();
  final walletBalance = (userDoc.data()?['walletBalance'] ?? 0).toDouble();
  
  return walletBalance > creditLimit; // مثلاً: -30 > -50 = true (مسموح)
}

│  WRITE: wallet_ledger/{newId} = new entry               │
│                                                          │
└─────────────────────────────────────────────────────────┘

2.7 Rollback Strategy

في حالة فشل الـ Transaction:

Firestore Transaction يضمن Atomicity — إذا فشلت أي عملية كتابة، يتم التراجع تلقائياً عن جميع العمليات

لا حاجة لـ rollback يدوي

في حالة Network Failure أثناء الـ Transaction → لن يتم تأكيد أي تغيير

الـ Idempotency Flag (commissionDeducted) يحمي من التكرار عند Retry

2.8 Migration Strategy

للمتاجر الحالية

// Migration script (يُنفذ مرة واحدة)
// يضيف الحقول الجديدة لكل متجر موجود
async function migrateStores() {
  const stores = await db.collection('markets').get();
  const batch = db.batch();
  
  stores.docs.forEach(doc => {
    batch.update(doc.ref, {
      commissionRate: 5.0,
      commissionType: 'fixed',
      creditLimit: -50,
      totalCommissionsPaid: 0.0,
    });
  });
  
  await batch.commit();
}

### 2. إنشاء CommissionService

```dart
class CommissionService {
  /// خصم العمولة عند اكتمال الطلب — داخل Firestore Transaction
  Future<bool> deductOrderCommission({
    required String orderId,
    required String storeId,
    required String ownerId,
    required double orderTotal,
  }) async {
    return _firestore.runTransaction((txn) async {
      // 1. قراءة الطلب
      final orderRef = _firestore.collection('orders').doc(orderId);
      final orderSnap = await txn.get(orderRef);
      final orderData = orderSnap.data() ?? {};
      
      // 2. فحص Idempotency
      if (orderData['commissionDeducted'] == true) return false;
      
      // 3. قراءة إعدادات المتجر
      final storeRef = _firestore.collection('markets').doc(storeId);
      final storeSnap = await txn.get(storeRef);
      final storeData = storeSnap.data() ?? {};
      
      // 4. قراءة رصيد المستخدم
      final userRef = _firestore.collection('users').doc(ownerId);
      final userSnap = await txn.get(userRef);
      final currentBalance = (userSnap.data()?['walletBalance'] ?? 0.0).toDouble();
      
      // 5. حساب العمولة
      final rate = (storeData['commissionRate'] ?? 5.0).toDouble();
      final type = storeData['commissionType'] ?? 'fixed';
      double commission;
      if (type == 'percentage') {
        commission = orderTotal * (rate / 100);
      } else {
        commission = rate;
      }
      
      if (commission <= 0) return false;
      
      // 6. الخصم (يُسمح بالسالب)
      final newBalance = currentBalance - commission;
      
      // 7. كتابة التحديثات
      txn.update(orderRef, {
        'commissionDeducted': true,
        'commissionAmount': commission,
        'commissionDeductedAt': FieldValue.serverTimestamp(),
      });
      
      txn.update(userRef, {
        'walletBalance': newBalance,
      });
      
      txn.update(storeRef, {
        'totalCommissionsPaid': FieldValue.increment(commission),
        'lastCommissionAt': FieldValue.serverTimestamp(),
      });
      
      // 8. إنشاء سجل المحفظة
      final ledgerRef = _firestore.collection('wallet_ledger').doc();
      txn.set(ledgerRef, {
        'id': ledgerRef.id,
        'storeId': storeId,
        'userId': ownerId,
        'type': 'order_commission',
        'amount': -commission,
        'balanceBefore': currentBalance,
        'balanceAfter': newBalance,
        'referenceId': orderId,
        'referenceType': 'order',
        'description': 'عمولة طلب',
        'createdAt': FieldValue.serverTimestamp(),
        'metadata': {
          'orderId': orderId,
          'commissionType': type,
          'commissionRate': rate,
          'orderTotal': orderTotal,
        },
      });
      
      return true;
    });
  }
  
  /// فحص هل المتجر يمكنه استقبال طلبات جديدة
  Future<bool> canStoreReceiveNewOrders(String storeId) async {
    // ... implementation
  }
  
  /// جلب إعدادات العمولة العامة
  Future<Map<String, dynamic>> getCommissionConfig() async {
    // ... from commission_config/default
  }
}
```

```dart
class WalletNotificationService {
  static final Map<String, bool> _shownNotifications = {};
  
  /// تفحص الرصيد بعد كل عملية وترسل التنبيه المناسب
  static String? checkBalanceAndNotify(double balance, double creditLimit) {
    if (balance <= creditLimit) {
      return _showOnce('credit_exceeded', 'تم تجاوز الحد الائتماني! لن يتم استقبال طلبات جديدة.');
    }
    if (balance < 0) {
      return _showOnce('negative', 'تنبيه: رصيد محفظتك سالب (${balance.toStringAsFixed(2)} جنيه)');
    }
    if (balance < 10) {
      return _showOnce('below_10', 'تنبيه: رصيدك أقل من 10 جنيه');
    }
    if (balance < 20) {
      return _showOnce('below_20', 'تنبيه: رصيدك أقل من 20 جنيه');
    }
    if (balance < 50) {
      return _showOnce('below_50', 'تنبيه: رصيدك أقل من 50 جنيه');
    }
    return null;
  }
  
  static String? _showOnce(String key, String message) {
    if (_shownNotifications[key] == true) return null;
    _shownNotifications[key] = true;
    return message;
  }
  
  static void resetForNewBalance() {
    _shownNotifications.clear();
  }
}
```
